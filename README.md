# Customer Personality Segmentation

## Project Overview

This project explores customer demographics and purchasing behavior to identify distinct customer segments within a retail dataset. Using Python and unsupervised machine learning, the analysis applies K-Means clustering to group customers based on similarities in their characteristics and purchasing patterns.

The objective is to uncover meaningful customer segments that can help businesses better understand their customer base and make more informed marketing and customer engagement decisions.

## Business Objectives

- Explore customer demographics, income, and purchasing behavior.
- Identify patterns and relationships within customer data.
- Apply K-Means clustering to identify distinct customer segments.
- Evaluate clustering performance using the elbow method and silhouette analysis.
- Interpret customer segments and identify potential business opportunities.

## Tools & Technologies

- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn
- **Clustering:** K-Means
